# Providence: CCTV Analytics

A computer vision project that uses YOLOv8 to detect people and vehicles in CCTV footage and turn those detections into simple traffic analytics. Built as a learning project while exploring real-time inference and computer vision.

The system reads video from a file or camera, processes frames using OpenCV, and displays detection statistics in a live terminal dashboard. It can also generate annotated videos and log events.


Things I worked on:

* Object detection with YOLOv8
* Video processing with OpenCV
* Threaded frame capture
* Traffic density analysis
* A live terminal dashboard with Rich
* Event logging and annotated video output
